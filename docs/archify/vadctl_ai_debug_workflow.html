外部调用方 执行与安全门 证据存储 失败出口 虚线：dry-run / 失败路径

关键约束与人工兜底

  • MCP 服务器（vad-mcp）只是薄包装：转调 vadctl --json，不复制业务逻辑。
  • UIA 目标必须先提窗、再重读控件矩形、再校验 WindowFromPoint；被遮挡默认拒点，只有显式 --force 才绕过。
  • --dry-run 不执行任何动作、不提窗、不做断言，只解析目标并输出坐标/分数。
  • 任一步失败默认短路；证据目录保留成功与失败截图，供 AI 复核或人工重录参考图。
  • 坐标统一为物理像素；点击坐标使用 i32，支持副屏负坐标。
