# 发布稿件

本目录存放面向技术社区的使用教程稿件，内容均基于当前版本（1.0.5）的真实功能，发稿前请核对版本号。

| 文件 | 目标平台 | 特点 |
|------|----------|------|
| `csdn.md` | CSDN | 标题带关键词，步骤化，结尾带仓库地址 |
| `jianshu.md` | 简书 | 叙事向，弱化技术术语，讲「为什么这么设计」 |
| `oschina.md` | 开源中国 | 架构与取舍为主，面向开发者，偏技术深度 |

通用教程（README 里链接的那份）是 `docs/TUTORIAL.md`，三份稿件是它的平台化改写，不做重复粘贴，避免平台判重。

## 发布步骤

1. 打开对应平台，用 Markdown 编辑器新建文章，粘贴稿件全文。
2. 标题直接用稿件一级标题；CSDN 可再加一行副标题。
3. 分类建议：CSDN 选「人工智能 / 自动化」或「开发工具」，简书选「程序员」，开源中国选「软件工程」或项目博客。
4. 标签建议：自动化、RPA、开源、Tauri、Rust、桌面应用。
5. 文末仓库链接与教程链接保持原样。

## 注意事项

- 发布前确认 Releases 里有对应版本的安装包，下载链接不要写错。
- 平台对站外链接有限制（尤其 CSDN 新号），必要时把仓库地址放在文末「关于作者」段。
- 三个平台不要同一分钟连发，错开半小时以上更像正常投稿。
